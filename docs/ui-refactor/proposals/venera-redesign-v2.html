venera 重设计 · 三个结构方向

上次的「墨韵」之所以看起来和原来差不多，是因为它只做了减法——去掉卡片边框、去掉阴影、换个灰调种子色。 但屏幕上的骨架一点没动：还是「问候语 + 搜索条 + 标题 + 横向列表 + 标题 + 网格 + 标题 + 网格」的同一套节奏。

这次三个方向动手的地方不一样：A 改的是「谁占据屏幕」，B 改的是「阅读节奏」，C 改的是「信息密度」。 每个方向三屏：首页 / 详情 / 章节。下面可以直接对比。

A

影院

Cinematic

让封面吃满屏幕。现在首页最上面是一句问候语——信息量为零，占着黄金位置。 这个方向把最上面 40% 让给「你正在读的那本的封面」，标题压在封面上，进度条横贯全宽。 下面是横向书脊轨道，再往下才是网格。视觉重心从「文字」挪到「图」。

章节 · 顺序切换做成显式二选一

方向 A · 改了这些

  • 问候语整块删掉。「晚上好」占着首屏最大的字号，却一条信息都没有。改成封面主导，日期挪到顶部小字。
  • 继续阅读从「列表」变成「主视觉」。现在是一个 44×60 的小封面配一行字；改成整屏宽的出血封面 + 压在图上的衬线大标题。
  • 底栏从贴边变悬浮胶囊。内容可以延伸到栏后，滚动手感更连续。选中态是「浅色填充 + 一个小红点」，不是颜色突变。
  • 详情页封面当成全屏背景，而不是左上一个 144px 的小方块。标题压在渐变上，视觉冲击完全不一样。
  • 顺序切换做成两个并排按钮（214 → 1 / 1 → 214），替掉那个没人认得出的图标。注意：现有倒序功能本身是好的，只是藏起来了——主人就没想到标题栏右边那个按钮就是它。这里只是让它更容易被发现。
  • 代价：首屏能看到的书目变少了，翻找效率略降。适合「追更」为主、不是「大海捞针」的用法。
B

杂志

Editorial

把阅读节奏做成排版。这个方向完全不靠图说话，靠字——衬线大标题、全大写小字标签、粗细不一的横线。 忘掉「卡片」，想象一本印刷的目录页：章节表是编号索引，推荐是带说明的双栏特稿。 改动最大的是「呼吸感」和「层级」，不是颜色。

方向 B · 改了这些

  • 引入「报头」概念。顶部一条粗横线 + 全大写小字标的，像翻开一本杂志的封面。现在软件顶部什么都没有。
  • 继续阅读变成编号目录。01 02 03 的等宽编号 + 衬线书名 + 细分割线。比现在的小封面列表更有「这是本书」的感觉。
  • 封面改成直角、硬阴影。不是圆角卡片，是「贴在纸上的一张图」。这一条最能让观感脱离「通用 App」。
  • 标签排成一列连续的词，不是一个个独立的胶囊 chip。像杂志的关键词栏。
  • 章节表变成双栏索引（编号 + 标题），像书的目录页。已读的用朱红编号区分，不整行变灰。
  • 代价：信息密度中等，靠「留白和字」撑场面，暗色下要小心别糊。需要打包衬线字体（Noto Serif SC 子集约 2–5MB）。
C

数据

Dense / Instrument

把 App 当仪表盘用。不追求好看，追求「一眼扫完、数字清楚」。 顶部一条 统计条（待读 / 更新 / 收藏 / 今日时长），列表全是等高紧凑行，右侧永远对齐着进度百分比。 等宽数字、细分隔线、极小字号标签。改动最大的是信息密度——同屏能看到的东西翻倍。

方向 C · 改了这些

  • 顶部加一条统计带（待读 / 更新 / 收藏 / 今日时长）。这四个数字现在散落各处，集中起来就有了「进度感」。
  • 继续阅读改成等高紧凑行，右侧永远对齐 64% 和 42/214。等宽数字保证小数点不动。
  • 章节网格从 2 列变 5 列，格子只放数字（42 而不是「第 42 话」）。现在手机上是 maxCrossAxisExtent: 250 算出 2 列 / 每格 48 高，一屏只能看到 8～10 话；改成 5 列 31 高后一屏能看到 15 话。这是本方向最实在的一条改善。
  • 直接给「最后一话」一个按钮——这是主人原本提的那个痛点，一行代码就能加。
  • 底栏能带角标（收藏 3），一眼知道有多少更新。
  • 代价：信息密度高，视觉上偏「工具」不偏「享受」。适合列表几百部、重度使用的人。

三个方向的本质区别

  • A 影院：换的是主视觉。封面吃满屏，标题压在图上。看起来最「不像原来的 App」。
  • B 杂志：换的是排版语言。衬线 + 横线 + 编号索引，直角封面。最有「质感」但也最考验字体。
  • C 数据：换的是信息架构。统计条 + 紧凑行 + 等宽数字。最实用，也最不像「重设计」。
共用的朱砂红，只作信号（更新点 / 进度 / 已读） C 用的是冷静的蓝，强调「仪表」感 B 用的是锈红，偏纸张暖调

三个方向都保留：底栏四个主入口、搜索、设置。业务逻辑、数据层、漫画源机制一律不动—— 只换「长什么样」和「东西放哪」。选定之后，我会把它落成真正的 Dart 代码，而不是停在这张图。
