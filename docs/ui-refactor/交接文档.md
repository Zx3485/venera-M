## 一、决策时间线

3. **约束**：不改业务逻辑 / 网络 / 存储层；设置项语义保留。

## 三、设计 Token（`lib/components/consts.dart`，全项目禁止裸字面量）

```
圆角:  kRadiusXs=6 / S=10 / M=14 / L=20 / Pill=999（配套 kBRXs~kBRPill）
间距:  kSpaceXs=4 / S=8 / M=12 / L=16 / Xl=24 / 2Xl=32
动效:  kDurationFast=150ms / Normal=220ms / Slow=320ms；kCurve=easeOutCubic
描边:  kBorderHairline=0.8（唯一描边宽度）
阴影:  kOverlayShadows(brightness) 双层；玻璃描边 kGlassBorderColor(isDark)
玻璃:  kGlassBlurDefault=20 / kGlassOpacityDefault=0.18
墨韵:  kInkDarkBg=#101013 / kInkLightBg=#FAFAF8 / kInkSeed=#8A8F98
       kSerifStyle() 衬线标题（Noto Serif SC + 回退链）
       kSealColor(context) 朱砂信号色
语义色板: kSoftAmber/Teal/Red/Purple/Green/Blue/Pink/Indigo
       （_buildSoftSwatch 生成，配 context.useTextColor/useBackgroundColor 深浅自适应）
```

## 五、玻璃系统（`lib/components/glass.dart` + `effects.dart` + `appbar.dart` + `navigation_bar.dart`）

- `GlassCard`：暗色填充用 surface（非白，去灰雾）、`floating` 悬浮阴影参数
- `BlurEffect`：**sigma≤0 直接短路**（sigma=0 也是常驻合成层，移动端掉帧元凶）
- `glassInAppBar`：已接入 Appbar/SliverAppbar（原本是死设置）；**关磨砂 = 彻底实色**（不再退回 sigma=15 模糊）
- **NaviPane 底栏玻璃悬浮布局**（`_NaviMainViewState.build`）：
  - 玻璃开：Stack 悬浮底栏，内容延伸到栏后；内容 MediaQuery `padding.bottom += 58`（`NaviPaneState._kBottomBarHeight`）补滚动余量；**必须用 Builder 在 removePadding 之下取 innerMq**，否则状态栏高度双重注入（已踩坑并修复）
  - 玻璃关：原 Column 布局不变
  - 页面避让接口：`NaviPaneState.floatingBottomBarInset(context)` —— 悬浮元素（FAB 等）按此抬高
- 用户可调：设置→外观→ glassEffect 总开关 + glassOpacity/glassBlur/glassHighlight/glassInReader/glassInAppBar（glassOpacity 默认已改 0.3）

## 九、踩坑备忘（重要）

1. **bash heredoc → python 时 `\\n` 会被 JSON 双重转义**成真换行写进 dart 字符串——含反斜杠的内容一律用 Edit/Write 工具，不用 heredoc
2. `num.clamp()` 返回 num，传 double 参数要 `.toDouble()`（或 `math.max`）
3. 顶层函数没有 BuildContext（`adaptiveGlass` 暗色判断读 theme_mode + platformBrightness）
4. `const Text(...).tl` 不合法（.tl 是 String 扩展）；新文案记得同步 `assets/translation.json`（zh_CN/zh_TW）
5. 无开发者模式的 Windows：`flutter pub get` 卡插件 symlink，但依赖解析已完成，`analyze --no-pub` 不受影响；APK 构建不需要开发者模式
6. 本地 Flutter SDK：`C:\Game\AIWork\tools\flutter-3.41.4`（flutter-io.cn 镜像）
7. 后台命令网络错误会自动重试，可能出现「提交已完成但命令报错」假象——提交前先 `git log` 确认
8. 本地 `pub get` 会重写 pubspec.lock（+131 依赖），提交前检查 lock 变更，必要时恢复
