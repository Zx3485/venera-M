## 已修复（commit a4b0668）

### ✅ P0-B 三处真源不一致

**问题**：`kHomeSections` 有 8 项（含 `'shelves'`），但 `appdata.dart` 里 `homeSections` 的默认值只有 7 项（不含 `'shelves'`），`kHomeSectionNames` 又是第 3 份列表。老用户升级后书架板块默认不可见。

**修复**：新增 `lib/foundation/home_section_defs.dart` 存纯常量（**不 import 任何东西**，避免 `appdata` ↔ `home_sections` 循环依赖），`appdata` 与 `home_sections` 都引用它。

```dart
const kHomeSectionDefs = <({String key, String name, bool defaultOn})>[
  (key: 'search', name: 'Search Bar', defaultOn: true),
  ...
  (key: 'shelves', name: 'Shelves', defaultOn: true),
];
```

### ✅ P0-A 书架内容不刷新

**问题**：`_ShelfCardState` 只在 `initState` 调 `_load()`。收藏夹里增删漫画后，父级 `setState` 重建但 State 被复用、`initState` 不重跑，导致封面条和计数都不更新，直到离开首页再回来。

**修复**：加 `didUpdateWidget` 比对 `folderComics` 计数，变了才重载。用计数比对而非每次 build 查库，避免引入新的性能问题。

### ✅ P1-D 改名失败静默无声

**问题**：`_MenuButton` 的 `catch` 是空的，而 `rename` 在重名/名字含双引号时会抛异常。用户看到对话框关闭、名字没变、毫无提示；且 `saveHomeShelves` 在 `try` 内不执行，书架引用会失配。

**修复**：改用 `showToast` 提示具体原因，失败时不关闭对话框。
